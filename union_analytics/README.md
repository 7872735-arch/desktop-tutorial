# 工會對話記錄分析系統

向驗廠官展示系統化追蹤工人訴求的管理工具。

## 快速開始

```bash
cd union_analytics
pip install -r requirements.txt
streamlit run app.py
```

## 功能

| 功能 | 說明 |
|------|------|
| 📂 多文件上傳 | 支持 CSV / Excel，可同時上傳多個月份記錄 |
| 📊 全年統計 | 總議題數、解決率、未解決數、平均解決天數 |
| 📈 月度趨勢 | 柱狀+折線複合圖，直觀顯示每月進展 |
| 🏆 Top 5 訴求 | 按類別統計最常見訴求，堆疊橫條圖 |
| ⏱️ 解決時間 | 按類別分佈的解決天數直方圖 |
| ⚠️ 未解決清單 | 本月尚未解決的議題列表 |
| 📤 下載報表 | 一鍵生成 HTML 驗廠報告 + 整合 CSV |

## 文件欄位說明

| 欄位名 | 說明 | 範例 |
|--------|------|------|
| `month` | 月份 | `2025-01` |
| `raise_date` | 議題提出日期 | `2025-01-15` |
| `issue_id` | 議題唯一編號 | `ISS-2025-001` |
| `category` | 議題類別 | `工資薪酬` |
| `description` | 議題描述 | 要求調整加班費... |
| `factory_response` | 廠方回應 | 管理層同意... |
| `status` | 解決狀態 | `已解決` 或 `未解決` |
| `resolution_date` | 解決日期（未解決留空）| `2025-01-28` |

## 議題類別建議

- 工資薪酬、工時休假、安全衛生、福利待遇
- 工作環境、勞動合同、管理溝通、其他

## 驗廠報表說明

HTML 報表包含：月度統計表、類別分析、未解決清單，可直接列印或在瀏覽器中展示。
